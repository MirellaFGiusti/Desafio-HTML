# 💻 Portfólio Web

Projeto desenvolvido durante o curso de **Desenvolvimento de Sistemas no SENAI**.

O objetivo foi criar uma página de portfólio utilizando **HTML5 semântico**, reunindo informações pessoais, habilidades, projetos e um formulário de contato.

## 🛠️ Tecnologias

- HTML5
- GitHub

## 📌 Sobre o projeto

A página possui:

- Cabeçalho com navegação
- Seção "Sobre mim"
- Foto de perfil
- Lista de habilidades
- Tabela com projetos
- Links para projetos no GitHub
- Formulário de contato
- Rodapé com informações de contato

## 📂 Projetos

Alguns dos projetos apresentados na página:

- [Projeto Loja de Games Retro](https://github.com/MirellaFGiusti/Projeto-Loja-de-Games-Retro)
- [Verificação de Idade](https://github.com/MirellaFGiusti/Verifica-o-de-idade)
- [Atividade Tipografia e Cores](https://github.com/MirellaFGiusti/Atividade-tipografiaCores)

## 📚 O que pratiquei

Neste desafio, pratiquei principalmente:

- Estrutura HTML5
- Tags semânticas
- Tabelas
- Formulários
- Links e âncoras
- Organização de conteúdo
- Inserção de imagens
